# سَندَ | SAND — حوّل فكرتك

نسخة تطوير منظّمة من واجهة سَندَ الأصلية. تم الحفاظ على واجهة React والشعار والفيديو المرفقين، واستبدال اعتماد `window.claude` بطلب API داخلي وتنزيلات متصفح عادية.

## ما الموجود؟
- واجهة React + Vite + Tailwind.
- خادم Express مع مسار `/api/ai`.
- مفتاح Anthropic يبقى في الخادم داخل `.env` ولا يُرسل إلى المتصفح.
- تنزيلات المتصفح بدل واجهة تنزيلات Claude.
- ملفات الشعار والفيديو الأصليان في `assets/`.

## التشغيل المحلي
يتطلب Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env
npm run dev
```

افتح `http://localhost:5173` للواجهة. الخادم المحلي يعمل على `http://localhost:8787`.

## تفعيل الذكاء الاصطناعي
1. احصل على مفتاح API من مزوّد الذكاء الاصطناعي الذي تختاره.
2. ضع المفتاح في `ANTHROPIC_API_KEY` داخل `.env` على جهازك أو منصة الاستضافة فقط.
3. أعد تشغيل الخادم.

**تنبيه تكلفة:** استخدام واجهة API قد يكون مدفوعًا حسب حساب المزوّد والاستهلاك. لا تضف مفتاحًا أو تفعّل فوترة إلا بعد مراجعة الأسعار والحدود. المشروع لا يحتوي مفتاحًا أو اشتراكًا مدمجًا.

## بناء نسخة الإنتاج
```bash
npm run build
npm start
```

ثم افتح المنفذ الذي يعرضه الخادم (افتراضيًا `8787`).

## الحالة الواقعية للخصائص الست
1. **الصور:** الواجهة الحالية تنتج رسومات SVG/PNG حسب تنفيذها؛ هذا ليس ربطًا بمولّد صور خارجي.
2. **الفيديو:** النموذج الحالي ينشئ مقطع WebM من مشاهد مرسومة في المتصفح؛ ليس توليد فيديو سينمائيًا من نموذج فيديو.
3. **الصوت والبودكاست:** القراءة تعتمد على صوت الجهاز عبر `speechSynthesis`؛ لا توجد خدمة TTS سحابية ولا تنزيل MP3 مدمج.
4. **العروض التقديمية:** يوجد تصدير PPTX/PDF في الواجهة، ويجب اختباره في بيئة التشغيل الجديدة.
5. **المستندات:** يلزم اختبار قراءة الأنواع المدعومة. تحليل الصور داخل المستندات غير موصول في هذا الإصدار.
6. **الجداول والخرائط والمخططات:** تعتمد على مخرجات الذكاء الاصطناعي ثم عرضها/تصديرها محليًا.

## ما لم يُنفّذ بعد
- مزود مستقل لتوليد الصور الحقيقية، ومزود فيديو، ومزود تحويل النص إلى صوت وتنزيل صوت.
- تسجيل دخول حقيقي، قاعدة بيانات، وحفظ مشاريع بين الجلسات.
- رفع الملفات إلى تخزين سحابي ومعالجة PDF/OCR آمنة.
- اختبارات متصفح شاملة؛ لم تُتحقق كل المسارات بعد.

لا تُعلن عن الخصائص على أنها جاهزة للإنتاج قبل توصيل المزوّدين المطلوبين واختبارها.
